// 06 — Reflection

Portfolio Reflection

Building this digital portfolio has been a more involved process than I expected in the best way possible, I used GitHub Pages to host the site, which was completely new territory for me. I had never published a live website before so learning how everything works was its own challenge on top of designing the site itself. I'm genuinely happy with how it turned out. The dark, cyberpunk-inspired color scheme with orange and gold tones reflects my personality a lot more than any default template would, and I made intentional choices around the fonts, layout, and section flow to make it easy to navigate for anyone visiting. The typography is clean and readable, and the site works well on both desktop and mobile.

The most difficult part of this process was getting everything published correctly especially attempting to do it from my phone at first, which made GitHub's interface far less intuitive than on a desktop. I learned quickly that tools matter, and switching to a laptop made a huge difference. Going forward, I plan to keep this site updated as I build more projects throughout my CS degree and eventually add coursework related to cybersecurity and privacy, which is my long-term focus. Resources I found helpful include GitHub's own documentation, YouTube tutorials on GitHub Pages, and just experimenting through trial and error. The biggest takeaway? Starting early is everything. Having a live portfolio already feels like a real head start.
